## DMIT 到底贵在哪、卡在哪

把 DMIT 的价格按机房拆开看，会发现它便宜的部分集中在洛杉矶入门款，贵的是香港和东京。

洛杉矶 Premium 系列里，公开的第三方整理给出 LAX.Pro.WEE 是 $36.9/年、LAX.Pro.TINY 是 $9.99/月，这两档是它最有竞争力的位置。往上一档，不同来源的报价就互相打架了（有的写 STARTER $38.90/月，有的写 $29.90/月），所以中高阶的具体数字不建议拿来当预算依据，直接去官网看当前价更准。香港 Pro 的 TINY 是 $39.9/月起，东京 Pro 大致在 $20–22/月这个量级。同样叫 CN2 GIA，香港的价格是洛杉矶的两倍以上。

拿它当标尺，就能算清"平替"的价格锚点该定在哪。搬瓦工 CN2 GIA-E 是 $169.99/年起，DMIT 洛杉矶 Pro 的 WEE 是 $36.9/年，两者差约 4.6 倍。也就是说，市场对"CN2 GIA + 年付"的心理价位其实横跨了 4 倍多的区间，而大部分人真正需要的那台机器，落在低端那一头。AkkoCloud 圣何塞的 ¥299/年正好压在这个位置。

比价格更容易被忽略的是使用限制，这几条都写在条款和 FAQ 里，买之前不看，用起来才知道：

- **不支持降级**。只能补差价升级，想降配得重新买一台。
- **不支持换机房**。买洛杉矶就是洛杉矶，想换香港要重新下单。
- **退款只有 3 天**，而且要求流量使用不超过 30GB。搬瓦工那边是 30 天退款（流量消耗低于 10%），窗口差了一个数量级。
- **默认关闭密码登录**。第一次连不上不是机器坏了，是要在控制台里手动开密码登录，或者配 SSH 密钥。
- **流量超了不停机**，改成限速，具体限到多少看套餐说明。

这几条合起来就是平替的机会窗口：愿意接受"不能换机房、退款期短"的人，完全没必要为这些功能付溢价。

## 平替合不合格，看这四项

**第一项，线路等级对不对得上你的运营商。** 国内三家的优质出口是分开的：电信走 CN2 GIA（AS4809），联通走 AS9929 或圣何塞机房的 AS4837，移动走 CMIN2（AS58807）。任何标着"CN2 GIA"的方案，对电信用户最直接；联通和移动用户要额外确认回程走的是哪条线，因为去程优化和回程优化经常不是一回事。这一条对 DMIT 成立，对 AkkoCloud 也成立——它三个机房都标 CN2 GIA，电信用户体验最稳，联通移动用户下单前值得先ping 一下测试 IP 看回程路由。

**第二项，是不是靠超售压价。** DMIT 缺货是常态，官方的说法是不超售，代价就是低价位套餐经常买不到。洛杉矶 Pro 和 Eyeball 的入门款最难抢，T1 系列相对有货，东京 Pro 库存好一些。一个平台如果长期有货又便宜得离谱，通常意味着资源是超卖的，晚高峰会现形。

**第三项，IP 被封之后的处理成本。** DMIT 的规则是 Pro 和 Eyeball 每 15 天可以免费换一次，在控制台点一下就行，不用开工单；其他情况按第三方说法是 $5/次。搬瓦工走的是另一条路——换机房绕开。AkkoCloud 的公开页面没有写换 IP 的具体规则，这一项属于下单前必须自己问清楚的。

**第四项，退款条款。** 这一项最容易被跳过。DMIT 是 3 天内、流量不超 30GB；搬瓦工是 30 天内、流量消耗低于 10%；AkkoCloud 的公开服务条款写明不支持退款。三个档次差得很清楚，第一次用某家机器的人，最好先买最短周期试一个月，别一上来就年付。
